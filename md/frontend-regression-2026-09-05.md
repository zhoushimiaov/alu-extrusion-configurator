# 前端续修与回归记录

## 本轮实际结果
- 双产品面板接入同一 BOM × 单价引擎与淘宝/1688 搜索链接。
- 纠正来源标注：现有单价与区间为未核验示例，不是实时卖家报价。
- 规格匹配优先于商品名称：修复 2020 立柱因名称含 2040 而按 2040 计价的问题；未知规格返回 unpriced，不再静默忽略。
- 持久化按产品隔离：光轴 hash 不再被型材 store 读取；非当前产品的延迟保存不覆盖当前 URL。
- 混合层板同时入场景；亚克力统计深度与几何 paneDepth 对齐。
- WebGL 降级路径 rodHandles 空指针加守卫；hotspots bounds 改为调用 active()。这两项尚未做完整浏览器降级测试。
- 修复面板自重永久显示计算中的问题。
- 算料导出把“净跨”改为“名义尺寸（m）”，明确长度基于未验证装配假设，不能用于生产。

## 验证
- npm test：8/8 通过。先复现规格错价、未知材料漏报、hash 串产品三个失败，再修复并通过。
- npm run build：通过，dist/index.html 598.07 kB。
- 浏览器：混合层板配置报价出现板件 ¥175；光轴报价 ¥267，刷新后保持；切回型材显示 ¥5572；最终页面自重 176.0 kg，并有未核验示例标记。淘宝链接关键词为 2020工业铝型材。
- 浏览器验证不等于几何/工程审核；没有检查 Excel/WPS 客户端，没有做所有极端配置及移动端性能测试。
